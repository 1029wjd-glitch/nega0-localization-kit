## 공개 키트 자체 검사

`python -m unittest discover -s tests -v`는 게임 데이터를 포함하지 않는 합성 자료로 아래를 검사한다.

- NORI 여러 줄 그룹 재배치와 번역하지 않은 옆 줄 보존, 손상 CRC 거부.
- BINF 12 UTF-16 단위 표시 한도, 내부 키 보존, row CRC 검증.
- MIKO 재포장 후 비대상 payload·원본 이름 bytes 보존.
- WAG에서 길이 변경 후 위치 의존 재인코딩, FTAG·비대상 payload 보존.
- 한글 매핑 생성/왕복, 원본 사설 슬롯 충돌 거부, NUL/비 BMP 입력 거부.
- Windows MSDelta 합성 파일 왕복(Windows에서만 실행).

2026-10-05 공개용 폴더·입력 경로로 위 합성 검사 9개를 실행해 모두 통과했다. 공개용 x86 네이티브 DLL과 C# 적용·복원 프로그램의 컴파일도 통과했다. 컴파일용 합성 문자 매핑과 생성 바이너리는 게시 대상에서 제외했다.

이 테스트는 기존 완성 패키지의 통합 검사나 실제 게임 실행을 대체하지 않는다. 공개용 코드의 입력 경로와 의존성 변경을 확인하기 위한 것이다. `source-provenance.json`은 그대로 옮겼거나 공개용으로 조정한 파일의 원본/공개 SHA-256을 제공한다.

## 사용자 확인과 남은 범위

**2026-10-05 사용자가 파일명 정렬 수정 후 한국어 로케일의 해당 장면을 정상 통과했다고 확인했다.** 이 관찰은 해당 장면의 플레이 검증이다. 일본어 환경의 의미적 호환성은 분석상 예상이며 전체 플레이 확인이 아니다. 모든 루트·전투·세이브 호환성도 전수 플레이되지 않았다.

문제를 보고할 때 패치 버전, 원본 EXE 해시, 시스템 로케일, 직접 실행/에뮬레이터 여부, 직전 장면과 정확한 오류를 함께 남긴다. 화면 문제는 대사·백로그·메뉴·전투 중 어디인지, 파일 문제는 ID·archive_chain·원본 바이트를 좁혀 확인한다. 변경 없는 전 구간 검사를 매번 반복하지 않는다.
